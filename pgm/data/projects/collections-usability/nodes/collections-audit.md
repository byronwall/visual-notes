# Collections usability audit

This project records the 2026-11-11 usability audit. It is an actionable backlog, not a claim that fixes are implemented. Source-confirmed findings are separated from browser observations and unverified integration risks.

Start with [the audit brief](../../../../../docs/intent/collections-usability-audit-2026-11-11/README.md), [likely ideal design](../../../../../docs/intent/collections-usability-audit-2026-11-11/ideal-design.md), and [reassessment protocol](../../../../../docs/intent/collections-usability-audit-2026-11-11/reassessment.md).

Retain the notes-native row model, editable embeds, working table features and body-save protection. Prioritize readable record detail, visible open/selection actions, phone layout and predictable keyboard behavior. Do not close a source-risk node without executing its reproducer. Evidence is synthetic because this repository is public.
