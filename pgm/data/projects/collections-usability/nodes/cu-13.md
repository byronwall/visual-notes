# CU-13 Show meaningful labels and missing review fields on cards

**Priority:** P2 · **Evidence:** Source verified; browser follow-up required · **Baseline:** `25c7a864947994b8f321ceab73e6b8eae14e3107`

## Current behavior

CardFields hides empty values and gives each property only an HTML title tooltip instead of a visible label. It calls ValueDisplay with wrap, which does not wrap plain text. Gallery defaults to body covers and can reserve a large empty image area when no cover exists.

## User impact and gap

Generic text values are ambiguous without hover, and missing rating/feedback fields vanish precisely when they may need attention. Switching to Gallery alone is not a complete mobile review solution.

## Reproduce

1. Create two text properties, an empty review field and several image-free rows.
2. Compare Board and Gallery at 390 and 1440px without hovering.
3. Try identifying which field is empty or which label a displayed value belongs to.

## Likely ideal and proposed work

Allow labelled summary fields and configurable empty-state prompts for workflow-relevant properties. Keep card fields intentionally selected. Prefer a coverless text-first card/list when images do not help the task.

## Acceptance and reassessment

- [ ] A touch user can identify each displayed value without tooltips.
- [ ] Configured missing review fields remain visible as actionable prompts.
- [ ] Long text has a clear path to full detail and blank covers do not dominate text-first collections.
